# Community Manager SOP — Firstweeks

## Role Overview

- **Title:** Community & Content Manager
- **Hours:** 20 hours/week (part-time, remote)
- **Reports to:** CMO
- **Budget:** $1,500-2,000/month
- **Start:** Immediate (Phase 1 can begin before hire using existing content assets)

---

## Day 1 Responsibilities

### Weekly Cadence (20h)

| Day | Hours | Focus |
|-----|-------|-------|
| Mon | 4 | Content creation + scheduling |
| Tue | 4 | Community engagement (Reddit, FB) |
| Wed | 3 | Content creation + UGC curation |
| Thu | 4 | Community engagement + response management |
| Fri | 3 | Analytics + reporting + planning |
| Sat-Sun | 2 | Weekend community monitoring |

### Daily Checklist

Each shift:
1. Check Reddit (r/beyondthebump, r/BabyBumps, r/newparents) — reply to mentions, engage trending threads
2. Check Facebook groups (5 target groups) — approve membership requests, engage discussion posts
3. Monitor TikTok and Instagram comments on Firstweeks content
4. Log 1-2 community insights (what are moms struggling with today?)
5. Update engagement tracker

---

## Screening Criteria

### Must-Haves
- Personal experience with postpartum period (own or close family/friend)
- Active Reddit account with 500+ karma in parenting subreddits
- Active Facebook account with membership in 3+ mom groups
- Understanding of HIPAA basics — never share identifiable health information
- Excellent written communication — warm, authentic, non-corporate voice

### Nice-to-Haves
- Experience with content scheduling tools (Buffer, Hootsuite, Later)
- Basic graphic design (Canva proficiency)
- TikTok content creation experience
- Previous community management role

### Red Flags
- Corporate/marketing-speak in sample writing
- Unsolicited medical advice tendency
- Unable to separate personal opinion from brand voice

---

## Voice & Tone Rules

Use the Firstweeks Brand Voice Guide (`brand-voice-and-messaging.md`):

- **Casual, not corporate.** "We" not "Firstweeks officially recommends"
- **Peer, not expert.** "I found this helpful" not "Studies show you should"
- **Permission-giving.** "It's okay if you're not tracking everything"
- **Never diagnose.** Flag, suggest, refer — never "you have X"
- **Never sell in first touch.** First 5 interactions in any group = value only

## First 90 Days Plan

### Month 1: Foundation

**Week 1-2: Seed**
- Join 5 target Facebook groups, 3 target subreddits
- Post 0 Firstweeks content — pure community value
- Build engagement tracker spreadsheet
- Establish posting cadence with 10 stockpiled value posts

**Week 3-4: Soft Launch**
- Begin subtle Firstweeks integration in relevant threads
- Post first quiz link in context (not as standalone)
- Create first 5 TikTok/IG assets
- Recruit first 3 ambassadors

### Month 2: Growth

**Week 5-6: Scale**
- Expand to 10 Facebook groups
- Launch weekly discussion series ("Thursday Check-In Thread")
- Activate ambassador program (first 5 ambassadors posting)
- Share first UGC piece on Firstweeks Instagram

**Week 7-8: Optimize**
- A/B test post timing and formats
- Double down on top-performing communities
- Run first community challenge ("2-Week Check-In Streak")
- Report viral coefficient first data

### Month 3: Sustain

**Week 9-12: Systematize**
- Handoff SOP to second CM (if scaling)
- Build content template library
- Automate scheduling with Buffer/Later
- Quarterly community health report to CMO

## Escalation Protocol

| Situation | Response | Escalate To |
|-----------|----------|-------------|
| User shares concerning symptom | "That sounds like something to discuss with your provider. Have you checked in with them?" | Never diagnose |
| User asks about pricing | Link to pricing page + offer discount code if appropriate | CMO for discount approval |
| User reports app bug | "Thanks for flagging — I'll pass this to the team" + log in bug tracker | CTO |
| User shares personal health data publicly | "This sounds personal — let's take this to DMs to protect your privacy" | CMO + CTO (HIPAA concern) |
| User is posting negative review | "I hear your frustration — can you DM me more details so I can help?" | CMO within 24h |
| Crisis (user mentions self-harm) | "You matter and help is available. Here's the Postpartum Support International hotline: 1-800-944-4773" | CMO immediately |
