# Pre-Filled LOI Drafts — Priority 5 Practices

**Purpose:** When a practice gives verbal or email interest, the LOI must go out within 48h (playbook SLA). These drafts are pre-filled with everything we already know so the sender only fills the `«...»` fields (contact, address, email, phone) and sends.

**Source template:** `materials/loi-template.md` (text unchanged — only pre-filled)
**Created:** 2026-09-30 | CMO
**Companion:** `response-conversion-playbook.md` §5 Meeting → LOI Fast Path

**Send checklist (per draft):**
1. Fill all `«...»` fields (contact name/title, address, email, phone, monthly postpartum volume).
2. Attach `materials/pilot-overview.md` + `materials/hipaa-summary.md` in the covering email.
3. Send from the CEO/human sender email; log the send row in `pipeline-tracker.md` Response Tracking Log.
4. Target signatory: practice manager or medical director (the champion).
